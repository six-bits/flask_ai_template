 ## Problem 2: Flash Sale Inventory Reservation Engine                                                                                                                                                             
                                                                                                                                                                                                                 
We're building an in-memory inventory reservation service for high-demand flash sales, like concert ticket drops or limited edition items. Each item has a fixed starting stock. When a customer starts checkout, they request a reservation lease that holds the items for 30 seconds.                                                                                                                                
                                                                                                                                                                                                                 
If the customer completes checkout within that 30-second window, the reservation turns into a confirmed order. If the lease expires or the user cancels, those reserved items must immediately return to the   available stock pool for other buyers.                                                                                                                                                                         
                                                                                                                                                                                                                 
The service must handle heavy concurrent requests racing for the last few remaining items, guarantee that stock is never oversold under any circumstances, enforce a maximum purchase limit per user to prevent hoarding, and allow users to check live stock levels. You'll get an initial list of items and inventory counts to start from. Before writing any code, walk us through how you'd break this down, the API you'd build, and the data model underneath it.
